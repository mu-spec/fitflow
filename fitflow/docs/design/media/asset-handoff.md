- Optional secondaryFrame is supported but no second frames are declared yet.
- Exact filenames below, lowercase canonical IDs. Never rename domain IDs to fit artwork.
- Dark premium indoor/home-gym photography, controlled lighting, realistic skin, neutral charcoal/black/deep-green fitness clothing.
- Teal environmental accents only where natural; no neon glow, embedded text/logos, clutter, cartoon anatomy, unrelated equipment, sexualized posing, or bodybuilding-stage styling.
- Verify each pose and equipment against the existing catalog instructions; keep that domain source authoritative.
- Static imagery does not replace instruction text or explain all movement phases/tempo.
- Record photographer/source, usage rights, subject releases where applicable, crop approval and technique review alongside the delivered asset.
- Same photographic files in light and dark modes; no image tint or duplicated theme assets.
